# my-films

مستودع لصناعة أفلام قصيرة بالكود باستخدام skill ‏[lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar).

## الاستخدام
1. افتح Claude Code (من الجوال أو الويب) وابدأ جلسة على هذا المستودع.
2. اكتب طلبك، مثلاً: «اصنع لي فيلم قصير عن ... بنمط الألوان المائية».
3. كل فيلم ينحفظ في مجلد خاص به داخل المستودع.

الـ skill موجودة في `.claude/skills/lemo-opuscar/` وتنحمّل تلقائياً في كل جلسة.
