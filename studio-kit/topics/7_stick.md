# مجالات المحتوى · رجل العود

كل مجال يتفرّع منه عدد لا ينتهي من المواضيع. ⭐ = الأقوى في الانتشار.

| | المجال | ما يشمله | لماذا ينتشر | أمثلة لما يمكن صنعه |
|---|---|---|---|---|
| ⭐ | **ماذا تفعل لو** | مواقف طوارئ وخطر وكيف تتصرف | يُحفظ ويُشارك جدًا | لو علقت في مصعد · لو اشتعلت النار · لو تهت في الصحراء |
| ⭐ | **السلامة والإسعافات** | إسعافات أولية ووقاية | فائدة قد تنقذ حياة | كيف تنقذ شخصًا يختنق · الحروق · السلامة في الطريق |
| ⭐ | **مواقف الحياة اليومية** | مواقف مضحكة أو محرجة وكيف تتصرف | يرى المشاهد نفسه | لو نسيت اسم شخص · زميل مزعج · موقف محرج في مطعم |
|  | **العمل والمقابلات** | الوظيفة والمدير والزملاء | فائدة للشباب | مقابلة العمل · كيف تطلب إجازة · أول يوم عمل |
|  | **الدراسة والجامعة** | المذاكرة والامتحانات والسكن | جمهور طلابي ضخم | ليلة الامتحان · كيف تنظم وقتك · السكن الجامعي |
| ⭐ | **العلاقات الاجتماعية** | الصداقة والعائلة والجيران | تفاعل وتعليقات | علامات الصديق المزيّف · كيف تعتذر · التعامل مع الحماة |
| ⭐ | **الاحتيال والحماية** | خدع النصب والاحتيال الإلكتروني | يحمي الناس ويُشارك | رسالة احتيال · مكالمة مشبوهة · عرض مغرٍ جدًا |
|  | **السفر** | المطار والفندق والغربة | تجربة مشتركة | أخطاء في المطار · لو ضاعت حقيبتك · السفر لأول مرة |
|  | **المال اليومي** | التسوق والفواتير والادخار | فائدة عملية | كيف لا تصرف راتبك · التسوق الذكي · الديون الصغيرة |
|  | **الصحة اليومية** | النوم والأكل والجلوس والشاشة | عادات يومية | أخطاء الجلوس · قبل النوم · شرب الماء |
| ⭐ | **علامات وتحليل** | علامات الكذب والتوتر ولغة الجسد | فضول كبير | علامات أن أحدًا يكذب · لغة الجسد في المقابلة · علامات التوتر |
|  | **الحقوق والقوانين** | حقوقك كمستهلك أو موظف ببساطة | معرفة مفيدة | حقك عند إرجاع منتج · حقوق الموظف · حقك في السفر |
|  | **التقنية اليومية** | الهاتف والإنترنت والخصوصية | يمسّ الجميع | احمِ حسابك · إدمان الهاتف · كلمة سر قوية |
| ⭐ | **مقارنات طريفة** | نحن قبل وبعد، الآباء والأبناء | ضحك ومشاركة | زمان واليوم · أنت في الامتحان مقابل بعده · الأم مقابل الأب |
|  | **الطبخ والمطبخ** | أخطاء وسلامة في المطبخ | عملي | أخطاء في الطبخ · سلامة الغاز · حفظ الطعام |
