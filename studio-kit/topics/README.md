**قواعد الاستعمال (للـ Agent):**
1. حين يطلب المستخدم فيديو بلا موضوع: اقترح 3 مواضيع من ملف الأسلوب (اثنان ⭐ وواحد 🔁)، بسطر واحد لكل موضوع.
2. لا تكرر موضوعًا موجودًا في `HISTORY.md`.
3. الهوك المكتوب هنا فكرة البداية فقط؛ أعد صياغته. **تحقق من كل رقم ومعلومة من مصدر موثوق** قبل الكتابة (القائمة كُتبت كأفكار، لا كحقائق نهائية)؛ إن لم تجد مصدرًا غيّر الموضوع.
4. عند كل فيديو جديد ناجح أو موضوع رائج تجده: أضفه إلى الملف المناسب بنفس الشكل.
5. الطول: 50 ثانية إلى 3 دقائق حسب الموضوع؛ ابدأ بالهوك فورًا واختم بسؤال للتعليقات.
6. احترم الحساسيات: لا سياسة حزبية، لا طائفية، لا سخرية من دين أو شعب، لا تفاصيل عنف.
